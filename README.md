## 📝 Project Description
**Code Learner** is a beginner-friendly web app designed to help students learn Python, JavaScript, and C++. Based on Claudia's needs as a CS educator in the classroom, the site is a solution for a lack of accessibility in free elementary CS education online. The site teaches coding concepts through guided tutorials, interactive coding exercises, and real-time test runs/feedback. The goal is to create a structured, motivating, and free coding experience for anyone who is new to CS.

## Technologies Used
- **Frontend**: React
- **Backend**: Node.js, Express
- **Database**: PostgreSQL
- **Deployment**: Render / Vercel / Netlify

## How to Run the Project Locally

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/code-learner.git
cd code-learner

Set Up the Frontend
cd frontend
npm install
npm start

Set Up the Backend
cd ../backend
npm install
node server.js

The frontend will (usually) run on http://localhost:3000 and backend on http://localhost:5000 (or another port).
